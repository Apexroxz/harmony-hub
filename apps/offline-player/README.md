# Layam Offline Audiophile Player (`apps/offline-player`)

Standalone, pure client-side local audiophile music player.

## Guarantees
- 100% offline & local (IndexedDB audio storage)
- Zero Supabase / Auth / Backend calls
- Full 10-Band Biquad Hardware Equalizer & Spatial Convolver
- Bit-perfect 24-bit/192kHz playback
- Zero telemetry or network leaks
